# إشارة (Isharah)

تطبيق أندرويد يعرض نافذة عائمة فيها أفاتار (رأس ويدان) يحوّل الترجمة المكتوبة (CC) الظاهرة على الشاشة إلى هجاء إصبعي وإشارات. عربي وإنجليزي.

- **نموذج أولي.** أوضاع اليدين في `app/src/main/assets/overlay/index.html` تقريبية ولم يراجعها مترجم إشارة. لا تعتمد عليها للتعلّم أو للتواصل الحقيقي.
- **الخصوصية:** التطبيق بلا إذن إنترنت (راجع `AndroidManifest.xml`). يقرأ نص الشاشة عبر خدمة إمكانية الوصول ليبحث عن الترجمة فقط، ولا يحفظه.
- **التثبيت:** حمّل `app-debug.apk` من صفحة Releases، ثم افتح التطبيق واتبع الخطوات داخله.
- **البناء:** يتم تلقائياً على GitHub Actions عند كل push إلى `main`.
